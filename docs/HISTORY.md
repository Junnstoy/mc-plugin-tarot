# 历史导入说明

本仓库在 2026-10-22 从本地实际留存的发布归档恢复，版本标签顺序如下。提交作者采用仓库所有者 GitHub noreply 地址，未公开个人邮箱。

- `datapack-initial`：最初数据包：22 张卡牌、五级升级与包装抽卡（`tarot_26_3.zip`）
- `v2.0.0`：数据包 V2：牌面贴图、技能粒子与音效（`tarot_26_3_v2.zip`）
- `v2.1.0`：数据包 V2.1：26.3 兼容修复（`tarot_26_3_v2_1.zip`）
- `v3.0.0`：转为 Paper 插件：彩虹卡牌、定时效果与背包升级（`TarotRainbow-3.0.0-source.zip`）
- `v3.0.1`：修复升级、满背包溢出与原版贴图回退（`TarotRainbow-3.0.1-source.zip`）
- `v3.1.0`：收集册：可取回收藏、羁绊奖励与收集特效（`TarotRainbow-3.1.0-source.zip`）
- `v3.1.1`：收集册专属资源与兼容修复（`TarotRainbow-3.1.1-source.zip`）
- `v3.2.0`：重整指令、个人收藏数据与唯一收集册（`TarotRainbow-3.2.0-source.zip`）
- `v3.3.0`：头顶光环、挂机翅膀与五秒技能蓄力（`TarotRainbow-3.3.0-source.zip`）
- `v3.3.1`：主手蓄力、降低粒子密度并修复效果切换（`TarotRainbow-3.3.1-source.zip`）
- `v3.4.0`：右键拆包、命令权限、时间绕过与 PAPI（`TarotRainbow-3.4.0-source.zip`）

初始数据包未标语义版本，使用 `datapack-initial`；V2、V2.1 分别统一标为 `v2.0.0`、`v2.1.0`。

V3.3.2 只有更新说明和辅助脚本，没有留存独立源码归档，因此不伪造该版本提交或标签；对应拆包改动已在 V3.4.0 中。

V3.4.0 资源包与 V3.1.1 资源包逐路径、逐字节一致，仅压缩包名称不同，所以继续沿用原资产。

各 tag 中 plugin、legacy/datapack 和 resource-pack 的导入文件均保留归档原始字节。清单记录原归档 SHA-256 和逐文件 SHA-256；资源包仅在变化的版本记录新的导入。

`tools/original/` 是导入时保留的辅助脚本，可能含本机路径和早期环境假设；未赋予它们不存在的历史日期。它们用于开发过程存档，并非通用安装器。

仓库不包含服务端世界、玩家存档、日志、第三方依赖、构建缓存或二进制发布 JAR。源代码历史不能重现没有留存的开发中间步骤。
