## 安装与使用

将 tarot_26_3.zip 放入世界 datapacks 文件夹，运行 `/minecraft:reload`，检查日志。
获取一个卡包：`/function tarot:give/pack`；一盒：`/function tarot:give/box`；一箱：`/function tarot:give/case`。需管理员执行；控制台用 `execute as 玩家名 run function ...`。
把包装放副手，按下潜行打开；背包不足时 /give 的物品会掉在地面，拆箱前建议清空背包或预备存储空间。
升级：主副手各放一张同名同等级卡，执行 `/trigger tarot_upgrade`；消耗两张，副手得到高一级卡。普通玩家可用。
测试指定卡：`/function tarot:give/1_1`，第一个数字为清单编号+1，第二个为等级1–5。

## 热停用与卸载

优先 `/function tarot:disable`：停止运行并清理在线玩家属性；保留包使后续清理仍可用。恢复运行：`/function tarot:enable`。
彻底删除前，应让曾使用技能的玩家上线执行 `/function tarot:reset_player`，再禁用数据包和删除文件。离线玩家属性无法由普通命令直接清理，不能承诺任意时刻无残留卸载。实体卡和包装不会自动消失。
