# 塔罗数据包 V2.1 修复说明

## 原因

用户日志中的启动失败定位为 `tarot:sneaking` 谓词解析失败，根因提示 `No key type in MapLike`。

旧包 `data/tarot/predicate/sneaking.json` 使用 `condition` 标识谓词类型。Minecraft 26.3 已将此字段改名为 `type`。修复包将其改为 `"type": "minecraft:entity_properties"`，其余潜行检测条件保持原样。

官方依据：https://www.minecraft.net/en-us/article/minecraft-java-edition-26-3 （Predicates 部分）

## 安装

1. 停止服务器。
2. 从世界的 datapacks 目录移出旧 `tarot_26_3_v2.zip`（以及其他旧版塔罗包），保存备份到该目录之外。
3. 放入 `tarot_26_3_v2_1.zip`，不要同时启用新旧版本。
4. 启动服务器。

资源包无需替换；没有改变牌面、技能、概率、升级规则或记分板名称。
