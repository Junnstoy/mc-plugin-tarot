# 彩虹塔罗 V3.2.0

## 普通玩家指令

| 指令 | 用途 |
| --- | --- |
| `/tarot` 或 `/tarot help` | 查看当前权限可用的指令与玩法 |
| `/tarot status` | 查看当前卡牌效果、到期时间及换牌冷却 |
| `/tarot album` | 直接打开自己的收藏界面，不发放物品 |
| `/tarot collection` | 查看个人收集进度、数量奖励与羁绊 |
| `/tarot aura` | 开关已解锁的跟随粒子 |
| `/tarot migrate` | 更新随身旧版卡牌、包装及卡册的外观标记 |

`album` 可在没有实体卡册时使用。存入的牌仍可取回；只有随身携带实体卡册时，收集属性和跟随粒子才生效。卡牌存取与升级限生存／冒险模式。

## 管理员指令

需要 OP 或 `tarot.admin` 权限；目标玩家需要在线。所有数量必须填写。

```text
/tarot give <玩家> card <牌编号1–22|中文牌名|all> <星级1–5> <数量1–64>
/tarot give <玩家> pack|box|case <数量1–64>
/tarot give <玩家> album 1
/tarot reset cd <玩家>
/tarot reset buffer <玩家>
```

示例：

```text
/tarot give Steve card 世界 3 2
/tarot give Steve card all 1 1
/tarot give Steve pack 8
/tarot give Steve album 1
/tarot reset cd Steve
/tarot reset buffer Steve
```

第一条发两张三星「世界」；第二条发全部 22 种一星牌，每种一张。`all` 后的数量表示每种牌的数量，22 张需要 22 个空格。卡牌不可堆叠，若整批放不下，本次发放全部取消，已有物品不变。

`reset cd` 仅重置换牌冷却，不延长、清除或升级当前卡牌效果。`reset buffer` 仅清除当前激活的塔罗卡牌效果和对应状态图标，保留换牌冷却、个人收藏、收藏属性及其他插件／药水效果。冷却按现实时间继续计时，离线及重启不会重置。

旧的 `/tarot card` 和 `/tarot clear` 已移除，输入时会提示新用法。帮助和 Tab 补全使用新语法。

## 个人卡册与唯一性

- 收藏只保存在 `plugins/TarotRainbow/albums/<玩家UUID>.yml`，实体卡册不携带收藏内容。
- 丢弃或转交卡册不会清空原玩家收藏。另一玩家捡到后，打开的是自己的收藏。
- `/tarot album` 只打开界面，连续执行、丢弃后再执行均不会生成新的册子。实体卡册用 `give <玩家> album 1` 发放。
- 每个玩家随身最多保留一本卡册；背包、副手、鼠标光标里的多余卡册会自动清理。重复发放不会增加数量。
- 唯一性按玩家随身物品检查；箱子或地面上的卡册仍可转交别人，进入玩家物品栏时检查去重。普通收纳袋不受影响。

## 更新

正常停服，备份 `plugins/TarotRainbow`，将旧版 `TarotRainbow-*.jar` 移出 `plugins`，放入 `TarotRainbow-3.2.0.jar` 后启动。保留原数据目录，旧卡牌计时与收藏会继续读取。使用新增的独立冷却存档后，不建议直接退回旧插件版本。

资源包继续使用 `tarot_resources_rainbow_v3_1_1.zip`，无需重新制作或更换。没有资源包时仍显示原版纸张／收纳袋。
