# 彩虹塔罗 V3.3.0

## 释放技能

将卡牌放入副手，对准空气**持续按住右键 5 秒**。不再需要潜行。主手若有食物、弓、盾等可使用物品，先腾空主手，避免原版主手操作抢占右键。

使用原版持续使用物品状态确认蓄力，单击后等待不会释放。松手、换卡、交换双手、切换快捷栏、打开背包、传送、死亡或下线会取消。蓄力不会消耗卡牌，只有成功完成时才开始 24 小时效果和 30 分钟换卡锁定。蓄力中不提前增加属性。

| 卡牌星级 | 五秒内逐步生成的释放特效 |
| --- | --- |
| 一星 | 小型红色地面光环 |
| 二星 | 橙金双环与四向星芒 |
| 三星 | 金色光环与五芒魔法阵 |
| 四星 | 绿色魔法阵与逐渐展开的小羽翼 |
| 五星 | 彩虹魔法阵、彩虹羽翼、对应卡牌的粒子画面 |

五星地面法阵约前 2.25 秒逐渐展开，羽翼约第 1～3.75 秒展开，卡面约第 2.5～5 秒逐渐显现。22 张卡使用各自现有贴图采样，显示彩色粒子卡面与边框；这是粒子点阵，不是完整分辨率贴图。

旧卡在上线、打开收藏／取出、迁移背包时自动补上持续使用组件。可执行 `/tarot migrate` 手动更新。资源包仍使用 V3.1.1，无需新增资源包；没有资源包时卡牌仍显示原版纸张。

卡包、盒、箱继续使用“副手持有＋潜行右键”拆开。原有升级、收藏、指令、属性和存档规则保持。

## 收集册跟随特效

一至五星的普通跟随效果全部移到头顶；圆弧逐渐增长到周长的 75%，转完后收束尾部，再停顿 1 秒进入下一圈。一圈为 3 秒旋转、1 秒收尾、1 秒停顿。

五星及全收集按红、橙、黄、绿、青、蓝、紫逐圈换色，七色循环。连续静止完成七个整圈（约 35 秒；中途停下需先完成残圈）后，用 2 秒展开对应挂机形态：

| 收集档位 | 挂机形态 |
| --- | --- |
| 一星 | 单层光环 |
| 二星 | 双层反向旋转光环 |
| 三星 | 星芒法阵与光环 |
| 四星 | 小型羽翼轮廓 |
| 五星 | 持续展开的彩虹边框大羽翼 |
| 全部 110 种 | 彩虹大羽翼与额外头顶冠环 |

移动会终止挂机形态、重新累计静止圈数；单纯转头不会打断。行走时圆弧仍持续运转，不会每步重新从零开始。释放技能蓄力时暂停收藏跟随动画，避免两套图案重叠。

使用原版 TRAIL 粒子，每 2 tick（正常 TPS 下 0.1 秒）补画，粒子寿命为 6 tick，通过重叠补画改善原来半秒一次的闪烁。移动或取消后旧点约 0.3 秒自然消失。客户端粒子设置和低帧率仍会影响显示；本插件不向隐身或不可见玩家强制显示特效。常规跟随每帧最多 152 点，五星释放最高 359 点，发送范围 32 格。

## 安装与验证

停服备份 `plugins/TarotRainbow`，把旧 `TarotRainbow-*.jar` 移出 `plugins`，放入 `TarotRainbow-3.3.0.jar` 后启动，保留原数据目录。本次未替换 E 盘正式服务器。

验证包括：动画几何与边界、七色轮换、七圈挂机、移动重置、五档释放分阶段、22 张不同卡面、Paper 粒子数据序列化、原版使用状态／提前松手／100 tick 完成／卡牌保留、旧卡迁移，以及原有满背包／升级／收藏／重启存档回归。测试使用实际 Paper 26.3-143 和模拟玩家事件；尚未进行真人客户端长按及游戏内渲染验收。

`彩虹塔罗V3.3粒子预览.html` 可在浏览器离线打开，展示真实几何采样的收集跟随动画；它是数学轨迹预览，不是游戏录像，也不包含技能释放动画。
