# 彩虹塔罗 V3.1.1 — 收集册专属外观

本次为收集册加入独立的彩虹像素贴图：深蓝紫封面、彩虹镶边、星芒纹章、扣带和彩色分页。背包和手持物品均使用该外观；收集册内部仍使用原有五页收藏界面。

## 更新方法

1. 正常停服，将旧 `TarotRainbow-3.1.0.jar`（或更旧版本）移出 `plugins` 目录备份，放入 `TarotRainbow-3.1.1.jar` 后启动。保留整个 `plugins/TarotRainbow` 数据文件夹。
2. 客户端安装并启用 `tarot_resources_rainbow_v3_1_1.zip`，关闭旧塔罗资源包。本包已包含110种卡牌、卡包、卡盒、卡箱、状态图标和新收集册，无需叠加旧包。
3. 旧收集册会在玩家上线、随身携带或打开时自动更新外观标记。也可执行 `/tarot migrate` 手动更新背包中的旧物品。箱子里的旧册子取到背包后会更新。

插件和资源包应一起更新：3.1.0 的册子没有专属外观标记，单换资源包仍会显示原版收纳袋。新玩家用 `/tarot album` 领取并打开收集册。

## 兼容行为

- 未加载资源包时，收集册仍显示原版收纳袋；卡牌和包装仍显示原版纸张。
- 普通收纳袋保持原版外观及打开、选中内容的模型显示。
- 外观更新保留册子的自定义名称、数量和其他物品数据，不修改玩家收藏进度和已存入的牌。
- 卡牌存取、数量奖励、羁绊、携带生效条件及跟随粒子保持3.1规则。
