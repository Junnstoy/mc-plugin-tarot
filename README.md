# 彩虹塔罗 / mc-plugin-tarot

当前快照：`v3.4.0`。右键拆包、命令权限、时间绕过与 PAPI。

此 Git 历史按版本顺序从实际留存的发布文件恢复。提交时间是导入时间，不代表原始开发时间；没有恢复未留存的中间编辑记录。

- `plugin/`：Paper 插件源码与配置（V3 起）。
- `legacy/datapack/`：早期数据包源码，仅用于历史参考。
- `resource-pack/`：对应资源包的可编辑文件。
- `docs/releases/`：各版本说明。
- `history/snapshots.json`：原始归档及逐文件 SHA-256，可核对导入内容。
